# design/ -- m3l-design, adopted

This repository follows **m3l-design**, the shared design system for
everything published under the `monte3l` GitHub org.

- **Source:** [github.com/monte3l/m3l-design](https://github.com/monte3l/m3l-design)
- **Version adopted:** `v1.3.2`
- **Tier:** content

## What "content tier" means here

This repository has no CSS, fonts, rendered pages or terminal colour of its
own, so it copies nothing from m3l-design. It follows the markdown rules only:
bold, not italics; GitHub alerts matched to severity, at most two in a row;
plain sentences; tables for tabular data.
